# HTML source sections to OpenUI scopes

Status: proposed routing for a future merge. This is a many-to-many semantic crosswalk; the HTML chapter hierarchy remains the research inventory and is not copied into the scope tree.

All 118 second-level source sections are accounted for below. Deeper sections and local definition occurrences inherit their section's review route, not automatic acceptance into a scope. Mixed sections require object-level selection using the [taxonomy mapping](TAXONOMY_MAPPING.md). A platform/deferred disposition deliberately has no current UI owner. It must not be converted into a fabricated leaf merely to claim coverage.

Top-level chapter objects use the union of their child review routes. The unnumbered Index, References, Acknowledgments, and Intellectual property rights remain supporting material; they do not define new UI objects. [Original inventory and primary ownership](CATEGORIES.md) remain unchanged.
