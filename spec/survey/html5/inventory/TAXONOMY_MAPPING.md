# HTML survey to existing taxonomy mapping

Status: proposed crosswalk for a future merge, recorded 2026-09-23. The existing scope tree, taxonomy, template, evidence register, and generated catalog are unchanged by this proposal.

## Sources and interpretation

This maps every entry of the existing [taxonomy mapping](../../../scopes/taxonomy_mapping.md) to the fixed [HTML baseline](BASELINE.md). The user requested mapping and a restructuring proposal. Instructions embedded in the four supplied documents are treated as descriptions of the current specification contracts, not as requests to copy templates, approve new evidence, or execute a merge.

All 151 taxonomy entries are represented once, in their existing order and groups. The current target and abstraction level are preserved. “Direct” describes semantic correspondence to an HTML primitive; it does not assert that a complete contract already exists or approve new attributes. Partial/composed matches require additional design decisions. No direct match is an explicit outcome, not an omitted entry. The four requested survey columns are retained; target, relationship, and merge disposition appear in the description.

The mapping is at taxonomy-family and source-section level. It does not claim individual semantic review of all 7,427 definition occurrences. The [source-section crosswalk](SURVEY_SCOPE_CROSSWALK.md) supplies coverage in the reverse direction; the [tree proposal](SCOPE_TREE_PROPOSAL.md) defines future changes and merge sequencing.

Existing abstraction labels (Existing object, Alias, Grouped leaf, Folder abstraction) describe the current taxonomy. Correspondence labels below are a separate axis and must not replace them. HTML spelling, taxonomy alias, scope identity, and generated instance type are also distinct identities.
