# Containers — OpenUI5 survey

Scope: [`scopes/Containers/scope.md`](../../scopes/Containers/scope.md).
Full survey of the Containers category against the pinned OpenUI5 commit —
41 matched classes across 8 sub-categories.

**Note on `sap.tnt.ToolPage`:** the §6 pilot slice originally placed this
class under Structural containers. C1's reconciliation found that B6/B7's
later, cross-library-evidenced Shell bar/App shell cluster analysis
supersedes that placement — `sap.tnt.ToolPage` is not rendered here; it
appears in `_taxonomy_findings.md` (C9) as a motivating object for that
proposed sub-category instead. See `C1_RECONCILIATION.md` for the full
reasoning.
