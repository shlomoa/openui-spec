# Value and resource pickers

[Windows and dialogs](README.md) · [Catalog index](../../README.md)

Provide application workspaces and focused interaction windows. The entries below describe value and resource pickers in terms of purpose, appearance, contents, and behavior.

## Direct objects

| Object name in Qt | Abstract object name | Object description | Links to the sources |
|---|---|---|---|
| <a id="qinputdialog"></a> `QInputDialog` | Single-value prompt | **Purpose:** Ask for one value without building a full form.<br><br>**Appearance:** A small prompt dialog with an input control and usually confirmation and cancellation buttons.<br><br>**Contents:** A label and a text field, multiline editor, numeric stepper, dropdown, or list depending on the requested value.<br><br>**Behavior:** Users enter or select a value, then accept or cancel. Numeric ranges and other input constraints are configurable. A live variant may omit the usual buttons. | [QInputDialog](https://doc.qt.io/qt-6/qinputdialog.html) |
| <a id="qfiledialog"></a> `QFileDialog` | File or folder picker | **Purpose:** Choose files or directories, or specify a save destination.<br><br>**Appearance:** A platform-native or Qt file browser with navigation, listings, and selection controls.<br><br>**Contents:** Folders and files, location or filename fields, filters, and open/save/cancel actions as appropriate.<br><br>**Behavior:** Users browse, filter, and select one or more allowed resources. Save mode can request overwrite confirmation. Actual reading or writing of the selected file is performed by the application. | [QFileDialog](https://doc.qt.io/qt-6/qfiledialog.html) |
| <a id="qcolordialog"></a> `QColorDialog` | Color picker dialog | **Purpose:** Choose a color for text, drawing, or another visual element.<br><br>**Appearance:** A native or Qt color panel with color choices and a current-color display; exact controls vary.<br><br>**Contents:** Color selectors, component values, optional custom swatches, and optionally transparency and screen sampling controls.<br><br>**Behavior:** Users adjust or sample a color, then accept or cancel. A live variant can update the target while changes are made. Available controls depend on the platform and configuration. | [QColorDialog](https://doc.qt.io/qt-6/qcolordialog.html) |
| <a id="qfontdialog"></a> `QFontDialog` | Font picker dialog | **Purpose:** Choose a typeface and related text settings together.<br><br>**Appearance:** A native or Qt font panel, typically with choice lists and a sample preview.<br><br>**Contents:** Font family, style, size, and available effects or filtering options.<br><br>**Behavior:** Users inspect and adjust the selection, then accept or cancel; a live panel can apply changes as they occur. Native panels can differ in their available options and filtering support. | [QFontDialog](https://doc.qt.io/qt-6/qfontdialog.html) |
