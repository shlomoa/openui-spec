# Shapes and paths

[Graphics surfaces and content](README.md) · [Catalog index](../../README.md)

Present visual scenes, graphical elements, and their composition. The entries below describe shapes and paths in terms of purpose, appearance, contents, and behavior.

## Direct objects

| Object name in Qt | Abstract object name | Object description | Links to the sources |
|---|---|---|---|
| <a id="qgraphicsellipseitem"></a> `QGraphicsEllipseItem` | Ellipse or circle | **Purpose:** Represent an ellipse, circle, or elliptical segment in a scene.<br><br>**Appearance:** A curved shape with a configurable outline and fill.<br><br>**Contents:** One geometric ellipse or segment; no built-in label or resize handles.<br><br>**Behavior:** The application can change geometry and styling. Selection and dragging are optional capabilities. Geometry-editing handles or tools must be supplied by the surrounding application. | [QGraphicsEllipseItem](https://doc.qt.io/qt-6/qgraphicsellipseitem.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |
| <a id="qgraphicsrectitem"></a> `QGraphicsRectItem` | Rectangle | **Purpose:** Represent a rectangular region in graphical content.<br><br>**Appearance:** A rectangle with configurable outline and fill.<br><br>**Contents:** One rectangle; any labels or editing handles are separate content.<br><br>**Behavior:** Its geometry and styling can be changed by the application. Selection and dragging require configuration; interactive resizing is not automatically provided by the shape. | [QGraphicsRectItem](https://doc.qt.io/qt-6/qgraphicsrectitem.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |
| <a id="qgraphicslineitem"></a> `QGraphicsLineItem` | Line | **Purpose:** Represent a straight segment such as a boundary or part of a diagram.<br><br>**Appearance:** A stroke with configurable color, width, and line style.<br><br>**Contents:** Two endpoints defining the segment; no built-in arrowhead or endpoint handles.<br><br>**Behavior:** The application controls endpoints and styling. Optional selection and movement operate on the item. Editing endpoints or treating the line as a semantic connection requires application behavior. | [QGraphicsLineItem](https://doc.qt.io/qt-6/qgraphicslineitem.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |
| <a id="qgraphicspolygonitem"></a> `QGraphicsPolygonItem` | Polygon | **Purpose:** Represent a shape made from connected vertices.<br><br>**Appearance:** A polygon with configurable stroke, fill, and fill rule.<br><br>**Contents:** An ordered set of points defining the shape.<br><br>**Behavior:** The application can replace its geometry and style. Selection and dragging are optional. Vertex editing and snapping are not supplied as a ready-made interaction. | [QGraphicsPolygonItem](https://doc.qt.io/qt-6/qgraphicspolygonitem.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |
| <a id="qgraphicspathitem"></a> `QGraphicsPathItem` | Custom path | **Purpose:** Represent custom curves, outlines, or compound geometry.<br><br>**Appearance:** A stroked or filled path, potentially combining curved and straight sections.<br><br>**Contents:** A path and its outline and fill treatments.<br><br>**Behavior:** Updates when the application changes the path or styling. It can be selectable or movable when configured. Drawing, reshaping, and control-point editing tools must be supplied separately. | [QGraphicsPathItem](https://doc.qt.io/qt-6/qgraphicspathitem.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |

Selection and dragging are available when configured; shape-specific editing handles and drawing tools are supplied by the surrounding application. See [shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html#GraphicsItemFlag-enum).
