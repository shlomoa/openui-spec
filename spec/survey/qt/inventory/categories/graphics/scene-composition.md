# Scene composition

[Graphics surfaces and content](README.md) · [Catalog index](../../README.md)

Present visual scenes, graphical elements, and their composition. The entries below describe scene composition in terms of purpose, appearance, contents, and behavior.

## Direct objects

| Object name in Qt | Abstract object name | Object description | Links to the sources |
|---|---|---|---|
| <a id="qgraphicsscene"></a> `QGraphicsScene` | Graphics content scene | **Purpose:** Collect and coordinate objects that form a graphical workspace.<br><br>**Appearance:** Has no independent visible frame; a graphics viewport displays its contents.<br><br>**Contents:** Graphical items and optional background or foreground drawing.<br><br>**Behavior:** Manages item placement, stacking, focus, and selection, and routes input from a view to items. Several views can show the same content with different visible regions or transformations. | [QGraphicsScene](https://doc.qt.io/qt-6/qgraphicsscene.html) |
| <a id="qgraphicswidget"></a> `QGraphicsWidget` | Graphics scene UI container | **Purpose:** Organize controls or custom UI content inside a graphics scene.<br><br>**Appearance:** A scene-based rectangular region, optionally with window-like decoration; its content determines its visible design.<br><br>**Contents:** Child graphical widgets, layouts, and application-defined content.<br><br>**Behavior:** Supports sizing, layout, focus, and keyboard navigation appropriate to its configuration. It participates in scene positioning and transformations. A plain instance can serve as a layout container without drawing a specialized control. | [QGraphicsWidget](https://doc.qt.io/qt-6/qgraphicswidget.html) |
| <a id="qgraphicsitemgroup"></a> `QGraphicsItemGroup` | Grouped graphics | **Purpose:** Keep related graphical objects together for manipulation.<br><br>**Appearance:** The combined appearance of its members, without an automatic visible group frame.<br><br>**Contents:** Multiple graphical items considered as one compound object.<br><br>**Behavior:** Group transformations affect the members together. When selection or movement is enabled, the group acts as a unit. Grouping and ungrouping are application-provided operations; member artwork remains individually defined. | [QGraphicsItemGroup](https://doc.qt.io/qt-6/qgraphicsitemgroup.html); [Shared graphics interaction](https://doc.qt.io/qt-6/qgraphicsitem.html) |
| <a id="qgraphicsanchorlayout"></a> `QGraphicsAnchorLayout` | Anchored arrangement | **Purpose:** Arrange graphical widgets through relationships between their edges or centers.<br><br>**Appearance:** No independent drawing; components appear aligned or spaced according to their anchors.<br><br>**Contents:** Graphical widgets or nested layouts, plus positional and spacing relationships.<br><br>**Behavior:** When the available region changes, the arrangement resolves those relationships while respecting size constraints. Anchoring determines positions rather than supplying a draggable connector or visible constraint line. | [QGraphicsAnchorLayout](https://doc.qt.io/qt-6/qgraphicsanchorlayout.html) |
| <a id="qgraphicsgridlayout"></a> `QGraphicsGridLayout` | Graphics grid arrangement | **Purpose:** Arrange graphical UI contents in rows and columns.<br><br>**Appearance:** An implied grid in a graphics scene, with configurable alignment and spacing.<br><br>**Contents:** Graphical widgets or nested layouts assigned to cells, optionally spanning several cells.<br><br>**Behavior:** Adapts cell allocation to available space, sizing preferences, and row or column stretch. It positions contents but does not draw table cells or provide data-table selection behavior. | [QGraphicsGridLayout](https://doc.qt.io/qt-6/qgraphicsgridlayout.html) |
| <a id="qgraphicslinearlayout"></a> `QGraphicsLinearLayout` | Graphics linear arrangement | **Purpose:** Arrange graphical UI contents along one axis.<br><br>**Appearance:** A row or column of scene-based controls separated by configured gaps.<br><br>**Contents:** Graphical widgets, nested layouts, and stretchable spacing.<br><br>**Behavior:** Repositions and resizes contents as space changes, according to alignment, size limits, and stretch. Orientation selects a horizontal or vertical sequence; the arrangement itself is not interactive. | [QGraphicsLinearLayout](https://doc.qt.io/qt-6/qgraphicslinearlayout.html) |
