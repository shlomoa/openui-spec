# Text and shortcuts

[Input and selection](README.md) · [Catalog index](../../README.md)

Enter values or choose among alternatives. The entries below describe text and shortcuts in terms of purpose, appearance, contents, and behavior.

## Direct objects

| Object name in Qt | Abstract object name | Object description | Links to the sources |
|---|---|---|---|
| <a id="qlineedit"></a> `QLineEdit` | Single-line text field | **Purpose:** Enter or inspect a short, single-line value.<br><br>**Appearance:** A compact text field with caret, selection highlight, optional placeholder, and optional clear button.<br><br>**Contents:** One line of plain text; optional leading or trailing actions.<br><br>**Behavior:** Supports selection, typing, clipboard operations, and undo/redo. Password modes conceal text. Read-only mode prevents editing, while masks or validation can constrain accepted input. | [QLineEdit](https://doc.qt.io/qt-6/qlineedit.html) |
| <a id="qplaintextedit"></a> `QPlainTextEdit` | Plain text editor | **Purpose:** Edit or read multiline plain text, including longer documents or logs.<br><br>**Appearance:** A text viewport with caret and selection; lines may wrap, and scroll bars expose overflow.<br><br>**Contents:** Paragraphs of plain text; optional highlighting can distinguish text without adding a rich document structure.<br><br>**Behavior:** Supports keyboard editing, selection, clipboard actions, undo/redo, and scrolling. Read-only use presents text without accepting edits. Wrapping and retained log length can be configured. | [QPlainTextEdit](https://doc.qt.io/qt-6/qplaintextedit.html) |
| <a id="qtextedit"></a> `QTextEdit` | Rich text editor | **Purpose:** Create, edit, or display formatted documents.<br><br>**Appearance:** A document-like text area with styled paragraphs, a caret, selection, and scroll bars when needed.<br><br>**Contents:** Formatted text, lists, tables, and images.<br><br>**Behavior:** Supports rich-text editing, selection, clipboard actions, undo/redo, and wrapping. Read-only mode is available. Formatting commands and toolbars are supplied by the surrounding application rather than appearing automatically. | [QTextEdit](https://doc.qt.io/qt-6/qtextedit.html) |
| <a id="qkeysequenceedit"></a> `QKeySequenceEdit` | Keyboard shortcut field | **Purpose:** Capture a shortcut by having the user press its keys.<br><br>**Appearance:** A field displaying a readable sequence of key combinations, optionally with a clear button.<br><br>**Contents:** Modifier and key names representing the recorded shortcut.<br><br>**Behavior:** Records when focused and finishes after a pause or a configured finishing key. It can accept multiple combinations, up to the configured limit. Assigning the captured shortcut to an action is the application's responsibility. | [QKeySequenceEdit](https://doc.qt.io/qt-6/qkeysequenceedit.html) |
| <a id="qcompleter"></a> `QCompleter` | Text completion | **Purpose:** Help finish text entry using suggested matches.<br><br>**Appearance:** A suggestion popup or an inline completion inside the associated input field; no independent frame of its own.<br><br>**Contents:** Candidate words, names, paths, or other strings supplied by the application.<br><br>**Behavior:** Updates suggestions as text changes. Users choose a candidate or continue typing. Matching, case handling, and popup versus inline presentation are configurable. | [QCompleter](https://doc.qt.io/qt-6/qcompleter.html) |
