# Collections and hierarchies

[Content and data presentation](README.md) · [Catalog index](../../README.md)

Present readable content and structured collections. The entries below describe collections and hierarchies in terms of purpose, appearance, contents, and behavior.

## Direct objects

| Object name in Qt | Abstract object name | Object description | Links to the sources |
|---|---|---|---|
| <a id="qlistview"></a> `QListView`, `QListWidget` | List or icon collection | **Purpose:** Browse a flat collection of choices or objects.<br><br>**Appearance:** Rows in a list or a field of labeled icons, with selected items highlighted.<br><br>**Contents:** Item text, optional icons, and configured item decorations or editors.<br><br>**Behavior:** Users navigate, select, and activate items. Single or multiple selection, editing, dragging, and rearrangement depend on configuration. Long collections scroll; icon layouts may wrap. Both Qt names describe this same UI concept. | [QListView](https://doc.qt.io/qt-6/qlistview.html); [QListWidget](https://doc.qt.io/qt-6/qlistwidget.html); [Collection interaction](https://doc.qt.io/qt-6/qabstractitemview.html) |
| <a id="qtableview"></a> `QTableView`, `QTableWidget` | Data table | **Purpose:** Compare or edit structured data across rows and columns.<br><br>**Appearance:** A cell grid with optional row and column headers, grid lines, and selection highlights.<br><br>**Contents:** Cells containing text, icons, check states, or configured editors; optional spanning cells.<br><br>**Behavior:** Users navigate and select cells, rows, or columns. Editing, sorting, resizing, and drag operations depend on configuration. Overflow scrolls. The two Qt names share the table concept. | [QTableView](https://doc.qt.io/qt-6/qtableview.html); [QTableWidget](https://doc.qt.io/qt-6/qtablewidget.html); [Collection interaction](https://doc.qt.io/qt-6/qabstractitemview.html) |
| <a id="qtreeview"></a> `QTreeView`, `QTreeWidget` | Hierarchical tree | **Purpose:** Explore parent-child relationships while retaining context.<br><br>**Appearance:** Indented rows with branch indicators and optional additional columns and headers.<br><br>**Contents:** Parent and child entries, labels, optional icons or check states, and configured editors.<br><br>**Behavior:** Users expand or collapse branches, navigate, and select entries. Editing, sorting, and drag-and-drop depend on setup. Collapsing a branch hides its descendants without removing them. | [QTreeView](https://doc.qt.io/qt-6/qtreeview.html); [QTreeWidget](https://doc.qt.io/qt-6/qtreewidget.html); [Collection interaction](https://doc.qt.io/qt-6/qabstractitemview.html) |
| <a id="qcolumnview"></a> `QColumnView` | Cascading column browser | **Purpose:** Browse a hierarchy while seeing successive levels side by side.<br><br>**Appearance:** Adjacent vertical lists with optional resize grips and a preview area.<br><br>**Contents:** Each column shows one hierarchy level; a following column shows children, and a preview can describe a leaf.<br><br>**Behavior:** Choosing an entry changes the subsequent columns to follow that path. Users move horizontally as depth increases and may resize columns. The application supplies any preview content. | [QColumnView](https://doc.qt.io/qt-6/qcolumnview.html); [Collection interaction](https://doc.qt.io/qt-6/qabstractitemview.html) |

The paired Qt names represent the same user-facing collection concept. Actual editing, selection, sorting, and drag behavior depend on the configuration and content. See [collection interaction](https://doc.qt.io/qt-6/qabstractitemview.html#details).
