# Behaviors

Review copy for the proposed additions AM-P03–05; no new root or subcategory is introduced. See the [extension proposal](../../SCOPE_EXTENSION_PROPOSAL.md).

Behaviors define reusable interaction capabilities that can be applied to pages, views, containers, and widgets.

## Objects

- [Drag and drop](../../../../../scopes/Behaviors/drag_and_drop.scope.md): A behavior that allows users to drag and drop elements within a page or view.
- [Resizable](../../../../../scopes/Behaviors/resizable.scope.md): A behavior that allows users to resize elements within a page or view.
- [Collapsible](collapsible.scope.md): A behavior that allows users to collapse and expand elements within a page or view.

- [Modal interaction](modal_interaction.scope.md): proposed coordination of modal focus, background interaction and dismissal requests.
- [Scrollable](scrollable.scope.md): proposed scrolling capability on an existing content region.
- [Scroll lock](scroll_lock.scope.md): proposed page-background scroll locking independent of internal scrolling.

## Boundaries

The Behaviors scope describes user-facing interaction capabilities. It does not require a specific event system, gesture library, browser API, animation model, or framework directive.

Behavior objects follow the shared [scope folder and attribute category rules](../../../../../scopes/scope.md).
