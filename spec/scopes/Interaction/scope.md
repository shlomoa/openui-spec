# Interaction

Interaction defines state, target, gesture, pointer, keyboard, focus, input, and change
event notions used by controls, behaviors, containers, and widgets.

## Objects

This scope is a folder-level abstraction for interaction vocabulary from
[`taxonomy_mapping.md`](../taxonomy_mapping.md). Concrete reusable behaviors remain in
[Behaviors](../Behaviors/scope.md).

## Boundaries

The Interaction scope describes user-facing interaction vocabulary; it does not require
a browser event API, gesture recognizer, state-management library, or target framework
binding syntax.

Interaction objects follow the shared [scope folder and attribute category rules](../scope.md).
