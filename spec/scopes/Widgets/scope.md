# Widgets

Widgets define reusable components that can be used in multiple pages or views.

## Objects

Common widgets include:

- [Chart](chart.scope.md): A visual representation of data, such as a bar, line, or pie chart, that summarizes a data series.
- [Table](table.scope.md): Tabular presentation of data with columns, rows, cells, a caption, header associations, and optional sorting, filtering, and pagination.
- [Data grid](data_grid.scope.md): An interactive tabular-data widget that may support cell focus, selection, editing, sorting, filtering, pagination, or keyboard grid navigation.
- [List](list.scope.md): An ordered, unordered, or description list of items with optional selection, links, sorting, filtering, and pagination.
- [Feedback widgets](feedback_widgets.scope.md): Tooltips, contextual help, alerts, toasts, snackbars, notifications, startup screens, illustrated messages, and narration or audio-description surfaces.
- [Media widgets](media_widgets.scope.md): Media players, camera previews, geographic maps, custom graphics surfaces, and graphics viewports.
- [Navigation widgets](navigation_widgets.scope.md): Navigation drawers, navigation rails, breadcrumbs, tree views, column browsers, pagination controls, and carousels.
- [Menu widgets](menu_widgets.scope.md): Menus, menu buttons, menubars, and context menus, including nested menus.

More complex widgets include:

- [Date/Time pickers](date_time_pickers.scope.md): Entering or selecting a date, a time, or both, as one value or a range; a calendar is optional.
- [Stepper](stepper.scope.md): Guides the user through a multi-step process as an ordered sequence of steps.
- [Dialog](dialog.scope.md): A modal or non-modal surface that overlays the page with a title, content, and actions.

## Boundaries

The Widgets scope describes reusable user-interface components. It does not require a specific charting library, data-grid implementation, input component, state-management model, or framework widget library.

Widget objects follow the shared [scope folder and attribute category rules](../scope.md).
