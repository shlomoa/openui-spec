# Views

Views define user-facing representations of business objects and workflows.

## Objects

- [Report](report.scope.md): A read-only data view for filtering, sorting, grouping, and paging through business data.
- [Form](form.scope.md): A read-write data view of form fields and form groups, with validation, submission, and dirty-state tracking.

## Boundaries

The Views scope describes data interaction patterns. It does not require a specific data source, service protocol, state-management library, table control, form framework, or validation engine.

View objects follow the shared [scope folder and attribute category rules](../scope.md).
