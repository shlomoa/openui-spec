# Material 3 glossary terms mapped to the OpenUI vocabulary

All 67 terms of the [Material 3 glossary](https://m3.material.io/foundations/glossary),
scraped 2026-10-11 (`Glossary – Material Design 3`), each with a candidate OpenUI alias.
This is a proposal for the owner: the OpenUI terms come from the
[glossary](../../spec/scopes/scope.md#glossary), the
[taxonomy mapping](../../spec/scopes/taxonomy_mapping.md) and the
[terminology changes](../../spec/archive/terminology.done.md). No term is added or renamed here.

- **Name** is the heading as it appears in the M3 glossary.
- **Detailed description** is the M3 text, unchanged.
- **Sources** link to the term's own entry in the glossary (by its anchor) and to the
  "Learn more" links of that entry.
- **Image**: the glossary page has no images. Where a Material Web component documents the
  term, its example image is shown instead; the source is named in the cell.
- The scrape is indexed in [SCRAP_INDEX.md](SCRAP_INDEX.md).

## Match summary

| Match        | Terms | Meaning                                                       |
| ------------ | ----- | ------------------------------------------------------------- |
| Exact        | 23    | the OpenUI term names the same concept                        |
| Alias        | 5     | OpenUI has the concept; the M3 name is a variant or a synonym |
| Narrower     | 1     | the M3 term is one case of a wider OpenUI term                |
| Broader      | 1     | the M3 term covers several OpenUI terms                       |
| Related      | 12    | the concepts overlap but no OpenUI term matches               |
| Homonym      | 4     | the same word means something else in OpenUI                  |
| Gap          | 14    | a concept OpenUI does not name                                |
| Out of scope | 7     | not UI vocabulary (documentation, product, platform)          |
